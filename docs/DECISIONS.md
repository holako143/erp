# RLM ERP — سجل القرارات الهندسية (DECISIONS.md)

### ADR 001: المعمارية النموذجية الموحدة (Modular Monolith)
- **القرار:** استخدام معمارية كتل برمجية متطورة (Modular Monolith) مع عزل منطقي للوحدات واستخدام TypeScript على كلا الطرفين.
- **السبب:** يوفر أمان الأنواع المتبادل، وتوافق تام بين الخادم والعميل، وتجنب تعقيد الشبكة في المراحل الأولى مع سهولة الاستخراج لاحقاً.

### ADR 002: معيار الباركود والتتبع الفريد
- **القرار:** دعم التوليد الرياضي الدقيق لخانة التحقق (Check Digit) لمعايير EAN-13 وEAN-8 مع خوارزمية Code 128 B-mode وتوليد QR عالي الدقة.
- **السبب:** ضمان التوافق مع أجهزة المسح الضوئي التجارية وقارئات الباركود المحمولة وكاميرات الجوال.

### ADR 003: المحاسبة بالقيد المزدوج والمنع الصارم للتعديل
- **القرار:** لا يمكن تعديل أو حذف أي قيد مالي مرحل، والتصحيح يتم عبر القيود العكسية (Reversing Entries) فقط مع التأكد الصارم من أن إجمالي المدين يساوي الدائن.
- **السبب:** الامتثال لمعايير المحاسبة الدولية ومنع التلاعب المالي وتوفير مسار تدقيق كامل.

### ADR 004: عزل بيانات المستأجرين
- **القرار:** فرض حقل `tenant_id` كقيد رئيسي في جميع النماذج والاستعلامات وحقنه في سياق كل عملية.
- **السبب:** حماية سرية بيانات الشركات ومنع أي تسريب بين المشتركين في منصة الـ SaaS.
