# RLM ERP — خطة الأمان وحماية البيانات (SECURITY_PLAN.md)

### 1. عزل المستأجرين (Tenant Isolation)
- عزل منطقي وفهرسي صارم على مستوى قاعدة البيانات مع إلحاق `tenant_id` بجميع الاستعلامات.
- منع التسريب العرضي عبر Data Access Layer موحد لا يسمح باستعلامات خام غير محددة المستأجر.

### 2. الصلاحيات وإدارة الوصول (RBAC)
- الأدوار القياسية المدمجة:
  - `SUPER_ADMIN`: إدارة المنصة، المستأجرين، والباقات
  - `COMPANY_ADMIN`: إدارة الشركة، الفروع، المستخدمين، والإعدادات
  - `ACCOUNTANT`: إدارة الحسابات، مراجعة واعتماد القيود، التقارير المالية
  - `WAREHOUSE_MANAGER`: استلام وصرف المخزون، الجرد، طباعة الباركود
  - `CASHIER`: عمليات نقطة البيع POS، فتح وإغلاق الورديات
  - `SALES_REP`: إصدار عروض الأسعار وفواتير المبيعات
  - `HR_MANAGER`: إدارة الموظفين، الحضور، ومسيرات الرواتب
- مصفوفة صلاحيات تفصيلية (Create, Read, Update, Delete, Approve, Export).

### 3. تدقيق العمليات (Audit Trail)
- كل عملية حساسة (إنشاء فاتورة، ترحيل قيد، صرف مخزون، تعديل سعر، تغيير صلاحية) تُسجل مع هوية المستخدم، عنوان IP، والتاريخ الدقيق، والبيانات قبل وبعد التعديل.

### 4. حواجز أمان الذكاء الاصطناعي (AI Guardrails)
- الذكاء الاصطناعي لا يملك أي صلاحيات مباشرة للكتابة في قاعدة البيانات المالية أو تعديل أرصدة المخزون.
- عمليات الذكاء الاصطناعي مقتصرة على: التحليل، الاستعلام، التلخيص، وتقديم التوصيات التي تتطلب موافقة بشرية صريحة.
