# RLM ERP — Enterprise Multi-Tenant ERP Platform
## وثيقة النظرة العامة للمشروع (PROJECT_OVERVIEW.md)

### 1. هوية المشروع والغرض التجاري
**RLM ERP** هو نظام تخطيط موارد المؤسسات (Enterprise Resource Planning) متكامل من الطراز العالمي، مبني كمنصة برمجية كخدمة (SaaS) متعددة المستأجرين (Multi-Tenant)، تدعم تعدد الشركات والفروع والمستودعات والعملات واللغات (العربية بالكامل RTL والإنجليزية LTR).

النظام مصمم ليكون منتجاً تجارياً حقيقياً جاهزاً للبيع بنظام الاشتراكات الشهرية والسنوية، ويوفر عزلاً تاماً لبيانات الشركات مع محرك باركود فريد وتتبع تفصيلي للأصناف والقطع الفردية، ومحاسبة مالية مزدوجة متوافقة مع المعايير المحاسبية الدولية، ونقاط بيع سريعة، وإدارة مخزون ومستودعات متقدمة WMS، وسلسلة مشتريات ومبيعات، وموارد بشرية وتصنيع ومشاريع وأصول وجودة وأسطول، مع طبقة ذكاء اصطناعي مؤسسي.

### 2. نطاق الوحدات الوظيفية (Core Modules Scope)
1. **النظام الأساسي والبنية التحتية (Core Platform & Infrastructure):**
   - تعدد المستأجرين (Multi-Tenant Isolation)
   - تعدد الشركات (Multi-Company) وتعدد الفروع (Multi-Branch) والمستودعات
   - إدارة الأدوار والصلاحيات الدقيقة (RBAC) وسجل التدقيق (Audit Trail)
   - دعم كامل للغتين العربية والإنجليزية مع RTL/LTR الفوري
   - لوحة تحكم قابلة للتخصيص ومحرك بحث عام (Command Palette Ctrl+K)
2. **محرك الباركود الفريد والتتبع (Unique ID & Traceability Engine):**
   - دعم معايير EAN-13, EAN-8, Code 128, Code 39, QR Code, Data Matrix, GS1-128
   - فصل صارم بين: معرف المنتج، باركود الصنف، معرف القطعة، الرقم التسلسلي، ورقم التشغيلة (Batch)
   - مصمم وطابع ملصقات حرارية وA4 مع قوالب متعددة
   - سجل تتبع دورة حياة القطعة (Traceability Timeline)
3. **إدارة المخزون والمستودعات (WMS & Inventory):**
   - مستودعات ومواقع تخزين هرمية (Zone - Aisle - Shelf - Bin)
   - استلام، صرف، تحويل بين المستودعات والفروع
   - جرد دوري، شامل، وأعمى، وتسويات جردية
   - تتبع تواريخ الصلاحية والدفعات وتقييم المخزون (FIFO والمتوسط المرجح)
4. **المشتريات وسلسلة التوريد (Purchasing & Procurement):**
   - طلبات الشراء، عروض الأسعار (RFQ)، أوامر الشراء واعتماداتها
   - فواتير المشتريات، توزيع التكاليف الإضافية (Landed Cost)، ومستحقات الموردين
5. **المبيعات وإدارة العملاء ونقاط البيع (Sales, CRM & POS):**
   - عروض الأسعار، أوامر البيع، الفواتير الضريبية
   - نقاط البيع السريعة (POS) مع دعم الورديات، الفواتير المعلقة، الدفع المتعدد، والطباعة الحرارية 80mm
   - CRM، حدود الائتمان، ونقاط الولاء
6. **المحاسبة والمالية المتكاملة (Full Double-Entry Accounting):**
   - شجرة حسابات قياسية (Chart of Accounts)
   - قيود يومية آلية ويدوية متوازنة إجبارياً (Debits = Credits)
   - قيود عكسية وتتبع المصادر ومراكز التكلفة
   - التقارير المالية: ميزان المراجعة، قائمة الدخل، الميزانية العمومية، التدفقات النقدية، الإقرارات الضريبية
7. **إدارة الأعمال المتخصصة (Business Management Modules):**
   - الموارد البشرية والرواتب (HR & Payroll) ومسيرات الأجور
   - الأصول الثابتة والصيانة الوقائية وجداول الإهلاك
   - التصنيع وقوائم المواد (BOM) ومراكز العمل
   - إدارة المشاريع والمهام والربحية
   - إدارة الجودة وفحص الاستلام والإجراءات التصحيحية
   - إدارة الأسطول والنقل والشحنات
8. **الميزات المتقدمة وذكاء الأعمال (BI & Advanced Features):**
   - لوحات مؤشرات الأداء الحيوية (KPIs)
   - محرك الحقول والمستندات المخصصة
   - محرك الموافقات ومسارات العمل (Workflows)
9. **طبقة الذكاء الاصطناعي المؤسسي (AI Enterprise Layer):**
   - مساعد تفاعلي ذكي يستعلم عن البيانات ويفسر المؤشرات
   - توقع نفاد المخزون وإعادة الطلب
   - استخراج وتدقيق الفواتير بالـ OCR الذكي
   - حواجز أمان لمنع أي تعديل مالي مباشر دون إذن بشري
10. **إدارة الاشتراكات والتأجير التجاري (SaaS Platform Portal):**
    - إدارة المستأجرين، الباقات، الاشتراكات، وتفعيل الوحدات حسب الباقة
