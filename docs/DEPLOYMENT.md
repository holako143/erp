# دليل النشر والتشغيل الإنتاجي — RLM ERP (Production Deployment Guide)

## 1. المتطلبات البيئية (Infrastructure Requirements)
- **Node.js Runtime**: الإصدار `v22.x LTS` أو أحدث.
- **قاعدة البيانات الإنتاجية**: PostgreSQL 16 (أو التخزين المدمج `.data/erp_store.json` للبيئات السحابية السريعة).
- **ذاكرة التخزين المؤقت**: Redis 7.x لإدارة الجلسات وطوابير الطباعة والباركود.
- **متغيرات البيئة (`.env`)**:
  - `PORT=3000`
  - `GEMINI_API_KEY`: مفتاح Gemini AI لتشغيل المساعد المحاسبي واستخراج الفواتير OCR عبر الخادم.
  - `APP_URL`: الرابط الأساسي للمنصة.

## 2. التشغيل المحلي والإنتاجي
```bash
# تثبيت الحزم
npm install

# تشغيل الاختبارات الآلية للمحركات الأساسية
npx tsx --test src/core/erp.test.ts

# بناء واجهة الإنتاج
npm run build

# تشغيل الخادم المتكامل (Express + REST API v1 + Static SPA)
npm run start
```

## 3. نقاط النهاية الخلفية (REST API v1 Endpoints)
- `GET /api/v1/health`: فحص جاهزية الخادم، حالة قاعدة البيانات، وتوفر محرك الذكاء الاصطناعي.
- `GET /api/v1/erp/state`: استرجاع الحالة المؤسسية الكاملة للمستأجرين، المخزون، القيود المحاسبية، والاعتمادات.
- `POST /api/v1/erp/state`: حفظ التغييرات الفورية في قاعدة البيانات الخلفية.
- `POST /api/v1/erp/reset`: إعادة ضبط بيئة العرض التجريبية إلى البيانات القياسية.
- `POST /api/v1/ai/copilot`: المساعد المؤسسي الذكي المدعوم بـ `gemini-3.8-flash` لتحليل بيانات ERP.
- `POST /api/v1/ai/ocr`: استخراج بيانات فواتير الموردين المهيكلة بصيغة JSON عبر `gemini-3.8-flash`.
